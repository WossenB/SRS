# User Manual

## Role-Based Access
- **Super Admin**: System configuration, final payroll approval.
- **HR Admin**: Employee lifecycle, initiating payroll runs.
- **Manager**: Team leave and timesheet approvals.
- **Employee**: Self-service (Apply for leave, view payslips).

## Common Workflows
### Applying for Leave
1. Navigate to "My Leave".
2. Click "Request Leave".
3. Select type and dates. Overlap validation will block conflicting requests.

### Running Payroll
1. Go to "Payroll".
2. Select Month and click "Initiate Run".
3. System will snapshot current tax rules and compute all active employees.
