# User Manual - Birrama HRMS

## 🔑 Role-Based Access
- **Super Admin**: System configuration (Tax/Pension), Role management, Audit trail.
- **HR Admin**: Employee lifecycle, Recruitment, Payroll execution, Performance calibration.
- **HR Officer**: Document verification, Onboarding, Training assistance.
- **Department Manager**: Team approvals (Leave/Timesheet), Performance reviews.
- **Employee (ESS)**: Profile management, Leave requests, Timesheet entry, Document upload.

## 🏢 Core Operations
### Employee Onboarding
1. Navigate to **Personnel**.
2. Click **Add Employee**.
3. Complete the 3-step wizard (Personal -> Job -> Financial).

### Payroll Execution
1. Navigate to **Payroll Engine**.
2. Click **New Run**.
3. System will auto-calculate based on active Tax Slabs.
4. Review results and **Lock & Approve**.

## 📅 Self-Service
### My Leave
- View balance and request new leave. Overlap validation prevents double-booking.

### My Documents
- Securely upload degrees, certifications, or IDs for HR verification.

## 📊 Analytics
- Use the **Analytics** tab to view real-time headcount, turnover, and recruitment pipeline charts.
